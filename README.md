# Foundations of Data Science — CMSE 830

This repository contains coursework, data exploration, visualization, and interactive data product development for CMSE 830: Foundations of Data Science.

## Project

### Books Recommender System

This project explores book ratings and metadata through an interactive Streamlit application.

**Current status:** Initial Streamlit prototype. Users can explore books, view book information, and examine rating distributions. Personalized recommendations are planned but have not yet been implemented.

**Technologies:** Python, Pandas, Streamlit, Matplotlib, Jupyter Notebook.

[View the Books Recommender System project](projects/books-recommender-system/README.md)
